Connecting Google Drive (one-time setup)

There's no Google sign-in inside Clinic EMR itself — you link the account in Google's own app, then just tell Clinic EMR which folder that app is syncing:

  1. On this computer, install Google Drive for Desktop (free, from Google) if it isn't already.
  2. Sign in there with a Google account owned by the clinic (not a personal one), and turn on 2-factor authentication on it.
  3. Note the folder it syncs to on this computer — usually something like C:\Users\Clinic\Google Drive\My Drive\. You can create a subfolder in there just for these backups, e.g. ...\My Drive\ClinicBackups.
  4. Paste that folder's path below and save it.

That's it — from then on, Clinic EMR writes an encrypted snapshot there every night, and Google Drive's own app uploads it whenever this computer has internet. Nothing else to configure, no tokens or API keys.
