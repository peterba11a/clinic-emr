Connect another device

Follow these steps on any other computer, laptop, or tablet in the clinic that should reach this system — a consultation-room laptop, a second reception desk, and so on. Nothing needs to be installed on it; it just needs a web browser.

1. Connect it to the same network

Make sure the new device is on the same WiFi/network as this computer (the one running Clinic EMR).

2. Open a browser and go to this address

{{ hostname_url }}

Use this address on every device — bookmark it. It keeps working even if this computer's numeric network address changes after a restart, because it's a fixed name (like a network printer's name) rather than a raw address.

3. Log in

Use the staff username and password given to that person. Staff accounts are managed under Admin → Staff accounts.

If that address doesn't work

Some older Windows or Android setups don't resolve .local names. As a fallback, try the numeric address below instead — but note this one can change if this computer restarts and the router assigns it a new address, so prefer the address above whenever it works:

{{ ip_url }}

If devices on this network regularly can't resolve .local names, there are two ways to make the numeric address above permanent — pick whichever is easier for you:

  1. Ask whoever manages the clinic's router to set a fixed ("static" or "reserved") address for this computer, or
  2. Run the script below once, directly on this computer — no router access needed.
