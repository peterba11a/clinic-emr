Connect another device

Follow these steps on any other computer, laptop, or tablet in the clinic that should reach this system — a consultation-room laptop, a second reception desk, and so on. Nothing needs to be installed on it; it just needs a web browser.

1. Connect it to the same network

Make sure the new device is on the same WiFi/network as this computer (the one running Clinic EMR).

2. Open a browser and go to this address

{{ ip_url }}

Use this address on every device — bookmark it. If Clinic EMR was set up with the installer's "Make this computer's network address permanent" option left ticked (the default), this address is already fixed and will never change, even after this computer restarts.

3. Log in

Use the staff username and password given to that person. Staff accounts are managed under Admin → Staff accounts.

Also usually works: a name instead of the number

This computer also advertises itself as a friendlier name, which some devices can use instead of the numeric address above:

{{ hostname_url }}

This works out of the box on macOS, iOS, Android, and modern Linux. Windows generally does not resolve it unless Apple's Bonjour is also installed on that device (it comes bundled with iTunes, or can be installed on its own as "Bonjour Print Services") — most clinic PCs won't have that, so don't rely on this for a Windows device. The numeric address above always works everywhere with nothing extra to install, which is why it's the one to hand out by default.
