User guide

How each role uses Clinic EMR

A staff member can hold more than one role (e.g. Nurse and Pharmacy), and Admin can see and do everything every other role can. This walks through the day-to-day flow for each one.

Reception

Registering, triaging, and billing patients

  1. Register a new patient, or search for a returning one by name or their patient code.
  2. Record the chief complaint, core vitals, and a triage priority (Emergency / Urgent / Routine) — this is what sorts the waiting queue, so the clinician sees it without re-asking.
  3. After the clinician has seen the patient, open their invoice to record a payment (partial payments are supported) and print a receipt.
  4. Print a copy of the prescription, referral letter, or visit summary for the patient to take with them, whenever it's needed.
Clinician

The encounter, diagnosis, and treatment

  1. Open the patient's visit from the queue — it's a tabbed record: Vitals, Complaints, History, Examination, Investigation, Diagnoses, Treatments, and Notes.
  2. Add diagnoses from the full ICD-10 list (or a clinic-specific term Admin has added), marked Confirmed or Preliminary.
  3. Order drugs or procedures in the Treatments tab — a drug searches live pharmacy stock as you type; a procedure is picked from the admin's price list so it bills correctly every time.
  4. Order lab or radiology investigations and record results when they're back — they show up directly in the Investigation tab.
  5. Admit a patient to a ward/bed when needed, and discharge them later with a discharge summary, a follow-up date, and any take-home medications (billed automatically).
  6. Write a referral letter, or print the visit summary / complete patient record — both pull together everything recorded for the visit (or every visit), not just a one-line summary.
Nurse

Vitals, dosing, and the inpatient stay

  1. Record vitals and add nursing notes during a visit or an admission.
  2. Log each dose given against a treatment order — every dose deducts stock and bills automatically, which matters most for a multi-day admission.
  3. When logging a dose, record any consumables used alongside it (syringe, gloves, cotton swabs...) — each is billed and deducted from stock on its own.
  4. Admit and discharge patients the same way a Clinician does, if that's part of the clinic's workflow.
Pharmacy

Stock and dispensing

  1. Keep the stock list up to date — drugs and consumable materials, with expiry dates.
  2. Dispense a drug against a visit; stock and that visit's bill update automatically.
  3. Watch for items running low — the stock list shows quantity on hand for everything.
Admin

Setting the clinic up and keeping it running

  1. Create a user account for each staff member and assign their role(s) — Admin → Users.
  2. Set up the billables price list (consultations, procedures, lab, radiology) and, if the clinic wants to charge for printing, a price per page — Admin → Billables.
  3. Add wards and beds with their nightly rates — Admin → Wards.
  4. Set the clinic's branding (name, logo, address, contacts, currency) — it then appears automatically on every printed document.
  5. Use Admin → Connect a device whenever a new computer or laptop needs to join the clinic's system.
  6. Set up and check on nightly backups — Admin → Backup status.
  7. Maintain the presenting-complaints list and any clinic-specific diagnosis terms used alongside the bundled ICD-10 list.

Every user, in every role, can change their own password at any time from the link next to their name — separate from Admin resetting someone else's password without knowing it.
