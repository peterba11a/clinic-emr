Free · Offline-first · No subscription

Electronic medical records for clinics that don't have a server room.

Clinic EMR runs entirely on one ordinary computer at the clinic — no internet connection required to use it day to day, no IT staff, and no monthly fees. Every other device on the clinic's network just opens it in a browser.

What it covers

Registration & queue

Patient registration with auto-generated codes, and a walk-in queue sorted by triage priority.

The clinical record

Vitals, complaints, history, examination, diagnoses (full ICD-10), treatments, and notes — for every visit.

Admissions

Admit to a ward/bed, run the inpatient stay, and discharge with pharmacy-linked take-home medications.

Pharmacy & billing

Stock-aware prescribing, automatic invoicing for drugs, procedures, lab, radiology, and bed charges.

Printing

Prescriptions, referrals, visit summaries, complete records, discharge summaries, and receipts — all printable at any point.

Automatic backups

A nightly encrypted backup written to a folder of your choice — point it at Google Drive and you're covered.

Built for real clinic conditions: works with no internet connection, keeps running on modest hardware, and never sends patient data anywhere the clinic doesn't control. See the install guide to get it running, or the user guide for a walkthrough of each role.

What it deliberately doesn't do

No insurance/claims processing. No lab-instrument or radiology-image (PACS) integration — lab and radiology are request/result tracking only. No cloud hosting, accounts, or subscription of any kind — everything runs on the clinic's own computer and its own Google Drive. No developer access to clinic data, ever.
