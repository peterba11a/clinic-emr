Install guide

Getting Clinic EMR running at the clinic

This covers the normal path — installing it on the one computer the clinic will use as its server — plus connecting other devices and setting up backups. It takes about 15 minutes the first time.

1. Install on the server computer

This should be whichever computer stays on at the clinic (a desktop is ideal, but any Windows 10/11 laptop works). Run ClinicEMR-Setup.exe and click through the installer.

Once installed, the app starts automatically every time the computer boots, and restarts itself if it ever crashes — nobody at the clinic needs to open anything by hand day to day. It opens a browser to itself automatically on this computer.

Leave "Make this computer's network address permanent" ticked during installation (it's on by default). This is what lets every other device in the clinic reach this computer at the same address forever, even after it restarts — see step 2.

First login: username admin, password admin123. Change this immediately — Admin → Users → edit the admin account — before entering any real patient data. Every user, Admin included, is asked to accept a short Terms of Use on first login, which explains who's responsible for the clinic's data.

2. Connect other devices

A consultation-room laptop, a reception desktop, a nurse's tablet — none of them need anything installed. They just open a browser and go to the server computer's address, shown on Admin → Connect a device — something like: 

http://192.168.1.50:8080

That's a fixed, numeric address — pinned permanently during installation (step 1) — so it works on every device with nothing extra to install, and it's what to hand out to staff by default. The same page also shows a friendlier name, http://clinicserver.local:8080, which works out of the box on macOS, iOS, Android, and modern Linux, but generally not on Windows unless Apple's Bonjour is separately installed there — so treat that name as a bonus, not something to rely on for a Windows device.

If the numeric address was ever left unpinned, or the server computer moves to a different network later, Admin → Connect a device has a one-click way to redo it — no reinstalling, no router access needed.

3. Set up backups

Every night, Clinic EMR makes an encrypted snapshot of the clinic's data and writes it to a local folder. Point that folder at a Google Drive for Desktop synced folder (Admin → Backup status) and Google's own sync client uploads it whenever the internet is available — Clinic EMR itself never talks to Google or any other cloud service directly.

  1. Install Google Drive for Desktop on the server computer.
  2. Sign in there with a Google account the clinic owns (not a personal one), with 2-factor authentication turned on.
  3. In Clinic EMR, go to Admin → Backup status and paste the path of the folder Google Drive syncs.

Until this is set up, a dismissible reminder banner shows on every page. Restoring onto a new machine (disaster recovery) is a single command once the backup folder has synced to it — see the project's README for the exact steps.

Running it without the installer (development/testing)

Only needed if you're working on the code itself, not for clinic use:

pip install -r requirements.txt
python app.py

Full technical details — project layout, building the installer yourself, the backup/restore format — are in the README in the source repository.
