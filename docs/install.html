Install guide

Getting Clinic EMR running at the clinic

This covers the normal path — installing it on the one computer the clinic will use as its server — plus connecting other devices and setting up backups. It takes about 15 minutes the first time.

1. Install on the server computer (This computer should stay on at all times the system is in use)

This should be whichever computer stays on at the clinic (a desktop is ideal, but any Windows 10/11 laptop works). Run ClinicEMR-Setup.exe and click through the installer.

Once installed, the app starts automatically every time the computer boots, and restarts itself if it ever crashes — nobody at the clinic needs to open anything by hand day to day. It opens a browser to itself automatically on this computer.

Leave "Make this computer's network address permanent" ticked during installation (it's on by default). This is what lets every other device in the clinic reach this computer at the same address forever, even after it restarts — see step 2.

First login: username admin, password admin123. Change this immediately — Admin → Users → edit the admin account — before entering any real patient data. Every user, Admin included, is asked to accept a short Terms of Use on first login, which explains who's responsible for the clinic's data.
